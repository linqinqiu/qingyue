# PROPOSAL-018: 框架脉络重整（结构 + 版面）

## 0. 用户口径

> 「咱们现在先整理框架脉络，**书库界面不变，其他的都要改**，重新规划」
> 追问「改到哪一层」→ 拍板：**结构 + 版面一起重做**。

所以这一份不是"再修几个细节"，是把除书库以外的所有界面重排一遍，
并且先把"界面由哪几层构成"这件事定下来，否则重排完还是 16 套外壳。

## 1. 冻结基准：书库不许漂移，而且要能证明

`tools/verify/frame-metrics.mjs frozen-20261003` 已存档（`out/frame-metrics-frozen-20261003.json`）。
书库在三个视口下的实测值就是锚：

| 视口 | 内容实占 | 两侧死白 | 底部死白 | masthead | 控件中位高 |
| --- | --- | --- | --- | --- | --- |
| desk-1440 | 1160×360 | 19% | 47% | 58px | 30px |
| desk-1180 | 1100×360 | 7% | 40% | 58px | 30px |
| mobile-390 | 380×560 | 3% | 24% | 24px | 30px |

**规矩**：以后每一波改版都要重跑 `frame-metrics` 并与这份对比，
`#library` 任一指标出界即判红（不是"看起来没变"，是数字没变）。
其余页面允许且**必须**朝 §3 的目标移动 —— 它们变红是好事，书库变红是事故。

## 2. 现状：两条分开说，因为一条是坏、一条是丑

### 2.1 结构（实测，可数）

- 弹窗外壳 **16 套类名 / 13 档宽度 / 9 种 max-height / 8 种阴影 / 4 种入场动画**；
  `.toc-rules-modal` 是 `.customize-dialog` 的整份复制；`.book-manage-sheet` 没有 `max-height` → 长列表撑破视口；
  另有 3 处用 inline style 覆盖 CSS。
- 遮罩 **4 套实现 / 4 档底色与模糊**；`Esc` 只覆盖 **8/24** 个弹窗，**12 个没有 Esc**；
  `Select` 与 `ContextMenu` 又各写一份独立 Esc。
- 关闭键 **11 种类名 / 5 档尺寸（30·32·36·无）**；`.shortcut-close` 在样式表 **0 命中**；
  可访问名 8 种写法；8 个弹窗没有 `role="dialog"`。
- 定位 **4 套**；`ContextMenu.tsx` 硬编码 `width=210 / row=34`，而 CSS 写 `min-width:196 / 32+2` —— **两份数值互相矛盾**；
  `Select` 与 `ContextMenu` 各自重复实现同一个"夹进视口 8px"。
- 复选框 **11 种容器 / 4 档尺寸，其中 4 处完全没声明**（吃 UA 默认）；强调色两种令牌混用。
- 原生 `<select>` **5 处** 与自研 `Select` **17 处** 并存，其中 3 处原生连专属样式都没有。
- **29 个类名挂在 TSX 上而样式表 0 命中**（`.form-group`、`.modal-actions`、`.empty-notice`、
  `.health-stop-btn`、`.shelf-order-clear`、`.shortcut-close` 等）。
- 术语 **9 种叫同一件事**：弹窗/对话框/面板/抽屉/栏/浮层/弹层/菜单/下拉。

### 2.2 版面（§0 那张表，摘要）

- **发现页在 1440×900 上只占 1160×120，底部死白 76%**；在 390 宽下**横向溢出**（这条是坏，不是丑）。
- **设置页两侧死白 50%**（720 列居中在 1440 屏上）；订阅 43%、备份 40%、关于 39%。
- 书源页控件中位高 **58px**（行高被撑大），书库/书架是 30px —— 同一应用两种密度。
- 「小标 + 大号衬线标题 + 一句说明书」还在：`kicker` 出现在 6 个页面，`prose>40字` 出现在订阅(2)/备份(1)/关于(4)。

## 3. 目标：先定"界面由哪几层构成"，再定每页长什么样

### 3.1 四层骨架（写进 CSS 结构，不靠自觉）

```
L1 外壳 shell        顶栏（冻结）+ 一级导航 + 内容视口
L2 页面原型 page     四种，见 §3.2，各页只能选一种
L3 浮层 overlay      一档外壳 + 一条遮罩 + 一颗关闭键 + 一个定位器（§3.3）
L4 控件 control      按钮 4 档 / 复选 1 档 / 选择器 1 套 / 行 2 档（§3.4）
```

### 3.2 四种页面原型（取代现在九种各自为政）

| 原型 | 用于 | 骨架 | 版面纪律（实测目标值） |
| --- | --- | --- | --- |
| **A 网格页** | 书库（冻结）、书架、发现 | 一行页头（标题+筛选+动作，**不许有说明文**）→ 满宽网格 | 两侧死白 ≤ 20%；底部死白 ≤ 10%；无横向溢出 |
| **B 主从页** | 书源、订阅、规则 | 左列表 / 右详情，两栏都吃满高度 | 两侧死白 ≤ 8%；行高收敛到 44–48px（现在 58） |
| **C 清单页** | 设置、关于、书签、更新日志 | 分组清单：`组标题 → 行（标题+一句话+动作）`，**单栏但限宽 900 且靠左排**，不再居中留一半空白 | 两侧死白 ≤ 25%；每行动作只有一颗主键 |
| **D 阅读器** | 阅读器 | 顶栏 + 正文 + 抽屉（不动冻结部分） | 跨章连续（今天已修）；浮层走 §3.3 |

关键取舍：**C 类页不再居中**。设置/关于/备份这类页现在把 720–880px 的列居中在 1440 屏上，
一半屏幕是空的；改成"限宽但靠左、右侧留给预览或空白收敛"，死白从 50% 降到 ≤25%。

### 3.3 浮层系统（一次定死，之后只准引用）

- **一档外壳** `.dialog-shell` + 三档宽度 `--dw-s:480 / --dw-m:680 / --dw-l:940`（都是 `min(Xpx, 94vw)`）。
  16 套外壳类名全部改成"外壳类 + 尺寸类"，**禁止**再出现第 17 套；禁止 inline style 覆盖宽高。
- **一条遮罩** `.overlay-backdrop`：一档底色+模糊、点遮罩必关、`Esc` 必关（由 `useEscapeClose` 统一挂，
  12 个缺 Esc 的补齐）、`role="dialog"` + `aria-label` 必填。
- **一颗关闭键** `.overlay-close`：一种尺寸 30×30、`aria-label="关闭"`、必带 `border:0/cursor:pointer/flex:none`。
- **一个定位器** `useOverlayPosition()`：`Select` 与右键菜单共用同一份夹取算式与常量，
  删掉 `ContextMenu.tsx` 里的 `210/34` 硬编码，改为读 CSS 实际值。
- **抽屉、悬浮条**保留自己的类（它们语义不同），但遮罩与关闭键必须走上面那一套。

### 3.4 控件档位（收敛到可数的几档）

- 按钮：`primary / subtle / ghost / danger` 四档 + `.is-wide` 一档，全部有全局基础规则（已在 0.5.1 做过一半）。
- 复选：一种尺寸 16px、一种 `accent-color` 令牌、一种容器结构。
- 选择器：**统一到自研 `Select`**，5 处原生 `<select>` 全部换掉（原生那 3 处无专属样式的尤其）。
- 行高：B 类页行 44–48px 一档，清单行 40px 一档，网格卡不变。

### 3.5 术语（只准四个词，写进判据）

浮层类只准叫 **弹窗 / 抽屉 / 菜单 / 悬浮条**；"对话框、面板、栏、浮层、弹层、下拉"作为界面文案与注释术语清除。
同一动作只准一个动词：`缓存`（动词）/ `离线`（状态）/ `下载`（禁止与上两者混用）。

## 4. 施工顺序（每步一个可验收、可回退的波）

| 波 | 内容 | 为什么这个顺序 | 实测 |
| --- | --- | --- | --- |
| **W1 事实性坏了的** | ① `ContextMenu` 两套数值互斥；② 12 个弹窗缺 `Esc`；③ `.shortcut-close` 等 29 个无样式类名；④ `role="dialog"`/`aria-label` 缺失；⑤ 发现页 390 宽**横向溢出** | 这些是"坏"不是"丑"，先修完再谈重排，否则重排判据会被它们污染 | **已做（0.6.1，2026-10-04）**：① 新增 `web/src/overlayGeometry.ts` 一份算式，菜单改成挂载后量真实矩形再夹，`Select` 的 340/288/34 只留 JS 一份；② 接 `useEscapeClose` 的文件 6→18；③ 扫出 35 项，2 项补真规则、4 项留作门禁锚点、其余删；④ `role="dialog"` 15→25 处并补 `aria-label`；⑤ 根因是 grid 子项缺 `min-width:0`（那颗 nowrap 芯片顶宽轨道），现在 27 屏 0 溢出。§5 的 1/2/3 三条判据已落地（冻结模式、浮层语义扫描、无样式类名扫描），另补一条"门禁选择器必须还长在界面上" |
| **W2 浮层系统** | 落 `.dialog-shell` + 遮罩 + 关闭键 + `useOverlayPosition`，16 套外壳并完 | 版面重排会大量用到浮层，先有统一件 | 未动。`overlayGeometry.ts` 只收了"定位"这一件；外壳/遮罩/关闭键仍是各写各的（新骨架 `qingyue/web/src/overlay/` 那套是干净的，等 W4 逐页搬） |
| **W3 控件与刻度** | 复选框、选择器统一、行高、间距/字号档位 | 重排每页都要用它们 | 未动 |
| **W4 A/B 类页重排** | 发现（最惨：76% 底部死白）→ 订阅 → 书源 → 规则 → 书架（只重排页头，网格卡不动） | 从问题最大的开始 | 未动。实测这一波之后仍未变：发现 1440 底部死白 64%、书源控件中位高 58px |
| **W5 C 类页重排** | 设置 → 备份 → 关于 → 书签 → 更新日志（去居中、去说明文、去 kicker） | 这批是"半块屏空白"的集中区 | 未动（设置两侧死白仍 50%）—— 等 §6 第 3 件拍板 |
| **W6 阅读器浮层收编** | 抽屉/书签/朗读条接 W2 的件 | 最后，因为它依赖前面全部 | 未动 |

**每波交付要求**：`npm test` 全绿 + 14 个门禁全绿 + `frame-metrics --compare` 里 `#library` 零漂移 +
该波目标页的死白/覆盖率朝 §3.2 收敛 + `:server:test` 失败集合与基线逐条相同 + 版本号与 CHANGELOG 各升一档。

## 5. 新增判据（改版必须有闸，不然下次又漂回来）

1. `frame-metrics` 加"冻结页"模式：`#library` 与 `frozen-20261003` 比，出界即红；其余页只报差值不判红。
2. **浮层结构判据**（`UiContract` 或新 `overlay-structure-check`）：
   - 样式表里 `position: fixed` 且含 `background: rgba(0,0,0,` 的"遮罩"类数量 **≤ 2**（挡片 + 抽屉挡片）；
   - TSX 里作为弹窗外壳的类名数量 **≤ 3**（`.dialog-shell` / `.reader-drawer` / `.tts-floating-bar`）；
   - 所有 `.dialog-shell` 使用者必须同时出现 `useEscapeClose` 与 `role="dialog"`；
   - `styles.css` 里 `min-width:196` 与 `ContextMenu.tsx` 里的常量**只能有一处**。
3. **无样式类名判据**：把"TSX 挂着而样式表 0 命中"从人工发现变成常驻扫描（白名单制，新增即红）——
   这条能自动逮到本轮那 29 个里的绝大多数。
4. **术语判据**：界面文案与注释里禁现"对话框/弹层/浮层"指代弹窗；`缓存/离线/下载` 不得混用为同一动作。
5. **反向对照**：故意加一个第 17 套外壳类名，判据必须红；故意删掉一个弹窗的 `useEscapeClose`，必须红。
