# PROPOSAL-019 阅读体验重做（A–F）

用户 2026-10-11：「书籍阅读界面及其功能，这方面的可以全改，毕竟目前的产物有很多问题」，
并点名三个上游要重点研究。本文定重做的范围、改法、验收与顺序 —— 确认后按此实施。

## 一、上游研究结论

| 仓库 | 性质 | 可借鉴 | 红线 |
| --- | --- | --- | --- |
| gedoor/legado | 原版 Android 阅读 | 书源 DSL 的求值语义（本项目已在实现） | 该仓库 2026-05-27 起**已被作者清空**，只剩一纸法律公告，无代码可读 |
| hectorqin/reader | 自部署书库 + 影音 | 交互与信息架构：精排保留出版方样式、TXT 编码识别、漫画自然页序、进度用**比例**而非像素、睡眠定时 / 倍速 | **AGPL-3.0，代码一行不得进本仓库**（与本项目 GPL-3.0 不等价，README「与参照项目的关系」已写明） |
| HapeLee/legado-with-MD3 | Legado 的 Material 3 重绘分支 | 翻页模式（覆盖 / 仿真 / 滑动 / 滚动）、阅读菜单可配置、简繁转换、阅读记录（时间轴 + 章节统计）、书籍备注、手柄翻页、平板布局 | GPL 系，可借交互与视觉；仍**不逐字拷代码** |

一句话：能借的是**交互与信息架构**，不是代码。实现全部自写。

## 二、现状与问题

现有能力见 README「能力 · 阅读」一节（滚动 / 分页、3 种翻页动画、7 皮肤 + 自定义皮肤、7 字体、
字号行距段距缩进边距版心分栏、背景色图、点击分区、TTS 三引擎、目录虚拟列表、看图层、离线）。
问题集中在四类：

1. **翻页手感**：动画只有 `slide / fade / none`，缺「覆盖」与「仿真」；分页网格（每章补齐整页、
   跨章页码落点）是自研的，改一处容易牵动另一处 —— 缺一层**可测的翻页状态机**。
2. **菜单布局**：阅读工具栏按钮写死在 `ReaderScreen.tsx` 里，位置与内容不可调。
3. **缺功能**：简繁转换、阅读记录 / 统计、笔记 / 划线 / 备注，一个都没有。
4. **结构**：`web/src/reader/ReaderScreen.tsx` **2758 行、单组件约 30 个 `useEffect`**，改任何一处都要通读整文件。

## 三、改动

### A 翻页引擎

- **目标**：翻页动画补齐 `覆盖`（新页从右盖住旧页，CSS transform 即可，不需 canvas）；
  `仿真`（卷页）暂不做，但要**留出接口**（`pageAnim` 值域与动画层分离，将来加 canvas 实现不返工）。
- **改法**：把「翻页状态机」从 ReaderScreen 里抽成 `reader/pageTurn.ts`（纯函数：当前页 → 下一页 /
  上一页 / 跳章 的窗口与动画决策），ReaderScreen 只负责渲染。分页网格 `readerFlow.ts` 保持不动，
  新状态机**调用**它而不是重写它。
- **验收**：`paginate-flow-check.mjs` + `reader-transition-check.mjs` 全绿；新增「覆盖动画」的
  DOM 断言（旧页与新页同帧存在、动画结束后只剩新页）。

### B 阅读菜单可配置

- **目标**：阅读工具栏（顶/中/底）的按钮集合与排列可由用户配置，像 MD3 的「菜单配置」。
- **改法**：定义菜单项清单（唯一来源，供工具栏与配置面板共用）；配置存 `readerSettings`
  （localStorage，与本机外观同档）；默认值 = 现在的布局，**不改不漂移**。
- **验收**：新增静态判据（配置项与工具栏同源、默认布局与旧版一致）；`ui-shell-check` 不回归。

### C 简繁转换

- **目标**：`关 / 简→繁 / 繁→简` 三态，作用在正文渲染前。
- **改法**：`reader/scriptConvert.ts` —— 一张常用字表 + 少量词组例外（避免「头发→頭發」这类逐字错），
  纯函数、可离线测。**不引第三方依赖**（OpenCC 之类会带几百 KB 进包，先不上）。
- **验收**：单测固定「常见字 + 例外词组 + 已是目标字形时不变」；界面设置项可切、可持久化。

### D 阅读记录 / 统计

- **目标**：按天记录读了多少（时间轴 + 按书 / 按章节维度）。
- **改法**：服务端新增轻量表 + 读写路由（记录只增不改）；前端在阅读页停留计时上报（节流），
  「我的 → 阅读记录」看时间轴。数据落在 `data/` 的 sqlite，进备份包（可选，后议）。
- **验收**：接口契约测试 + 一条「停留 30 秒 → 记录 +1」的门禁。

### E 笔记 / 划线 / 备注

- **目标**：选中正文可划线 + 写备注；书级备注；按书查看。
- **改法**：服务端表 `notes`（书 + 章节 + 起止偏移 + 文本 + 备注）；前端选区 → 浮层 → 保存。
  偏移用**章节内字符偏移**（不用像素 / 列号 —— 字号一改位置就跳，reader 那条教训）。
- **验收**：接口测试 + 一条「划线后刷新仍在」的门禁。

### F 结构拆分

- **目标**：把 `ReaderScreen.tsx` 拆成可维护的模块，**行为不变**。
- **改法**：先抽纯逻辑与子视图（目录抽屉、设置面板、朗读条、看图层已在别处），ReaderScreen 只留
  编排。**分步做**，每步跑一次门禁。
- **风险**：多个门禁靠选择器锚在阅读器 DOM 上 —— 拆之前先 `grep tools/verify` 出所有锚点，
  拆完逐条复跑；锚点动了就同步改门禁（不许"门禁红了先关掉"）。

## 四、顺序

**C（自足、零风险）→ B（可见、中风险）→ A（可见、高风险，先补动画再收状态机）→ D → E → F（贯穿）**。

F 不做一次性大爆炸：每完成一项，顺手把那一块的逻辑抽出去，最后 ReaderScreen 自然瘦下来。

## 五、红线

- 上游代码一行不进（reader 是 AGPL）。
- 门禁锚点若因结构变化而移动，**同步改门禁**，不许绕过。
- 版本号按「一天一版」走；每完成一项 → `CHANGELOG` 顶部那条补一句，跑 `version-check`。
