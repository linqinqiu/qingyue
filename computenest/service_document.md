# Legado 开源阅读服务端与 Web 客户端

## 1. 服务概述

**Legado Server** 是将知名开源阅读应用（Legado / 阅读 3.0）重构为纯 JVM 后端与现代化 React 19 Web 客户端的无头（Headless）阅读服务。

通过阿里云计算巢一键部署，您可以在几分钟内拥有一个专属的私有化云端书库与跨平台阅读器：
* **彻底跨平台**：无需安装客户端，随时随地在手机浏览器、电脑浏览器、平板或墨水屏设备上畅快阅读。
* **生态深度兼容**：原生兼容 Legado 丰富的开源书源生态，支持书源规则沙箱解析（Jsoup + JsonPath + Rhino JS）、书源导入/导出与订阅自动同步。
* **极致性能与离线持久化**：底层采用弹性容器实例（ECI）与文件存储（NAS），SQLite 数据库、书架进度与书籍封面持久化安全隔离，支持秒级冷启动与弹性变配。

## 3. 部署架构

本服务采用云原生高可用架构部署：
1. **网络入口**：弹性公网 IP（EIP）+ 安全组提供 Web 端访问通道。⚠️ 本模板的安全组入方向默认规则是 `8080/tcp` 对 **`0.0.0.0/0`（整个互联网）**放行，等于把这个无鉴权入口直接挂到公网；创建实例后**必须先把来源 IP 收紧成自己的白名单**，或在它前面加一层鉴权反向代理（详见 §5.2）。
2. **计算核心**：阿里云弹性容器实例（ECI），运行 Legado Server（Ktor + Kotlin JVM + React 19 前端）。
3. **持久存储**：阿里云通用型文件存储（NAS）通过 NFS 协议挂载至容器 `/data` 目录，确保书架、阅读进度与封面永久保存。

## 5. 快速上手使用指引

> ### ⚠️ 先读这段，再点开 WebUrl
> 本服务**刻意没有登录、没有密码、没有会话**，而计算巢这条路径给出的 `WebUrl` 是**公网可达**的地址，模板默认还把安全组 `8080/tcp` 对 `0.0.0.0/0`（整个互联网）放行。三者叠加的后果是：**任何拿到这条 URL 的人，都能直接读写你的整个书库**——包括书源、书架，以及**按域名共享的登录凭据**。这与本项目「默认只绑 `127.0.0.1`、绑定地址就是唯一的门」的安全模型正好相反：云端这条路把那道门挪到了公网上，而应用层不会替你挡。
>
> 所以**在点开 URL 之前**，请先二选一完成收口，二者都做最好：
> 1. **收紧来源 IP**：在安全组里把 `8080` 的 `SourceCidrIp` 从 `0.0.0.0/0` 改成你自己的公网 IP（白名单）；
> 2. **加一层鉴权反代**：在服务前面放 Nginx `auth_basic` / Caddy `basic_auth` / OAuth 代理，或走 SSH/隧道，别把裸端口直接对外。
>
> 若**只是自己看书**，就不要用云端这条路径——直接在本机跑，服务默认只绑回环，谁都不暴露。用完请**及时在计算巢控制台「删除服务实例」**释放 EIP 与资源，长期挂着的公网裸端口随时可能被人扫到。

### 5.1 访问服务
服务实例部署成功后，在计算巢服务实例详情页中查看 **`WebUrl`**（格式为 `http://<您的公网IP>:8080`），点击即可进入 Web 阅读器界面。

### 5.2 访问控制（重要）
本服务**没有登录、没有密码、没有会话**：能访问那个 URL 的人就等于拥有整个库（书源、书架、按域共享的登录凭据）。
计算巢这条路径给出的是**公网可达**的地址，所以：
1. 只在需要对外访问时创建实例，用完释放；
2. 长期使用时请在前面加一层 —— 反向代理 Basic/OAuth 鉴权、安全组 IP 白名单，或走 SSH/隧道；
3. 只是自己看书，就不要用云端这条路径，直接在本机跑（默认只绑 `127.0.0.1`）。

### 5.3 导入书源
1. 点击导航栏中的 **「书源管理」**。
2. 点击 **「导入网络书源」** 或 **「本地导入」**，粘贴 Legado 常用书源链接（JSON 格式）。
3. 导入后即可在搜索栏中全网并发检索书籍并一键加入书架。

## 6. 常见问题与运维

### Q1: 部署完成后提示 `HTTP ERROR 502` 或无法连接？
* 请确认访问链接是否包含了端口号 `:8080`（例如 `http://1.2.3.4:8080`）。直接访问 `http://1.2.3.4` 默认走 80 端口将无法打开。

### Q2: 想给这个服务加登录，怎么做？
* 服务本身刻意不做身份层（它是按"只绑回环、给一个人用"设计的）。要在公网上加登录，请在它前面放一个反向代理做鉴权（Nginx `auth_basic`、Caddy `basic_auth`、或 OAuth 代理），或者用安全组把来源 IP 限死；不要指望应用层帮你挡。

### Q3: 如何调整配置（变配）？
* 在计算巢控制台的 **「服务实例详情」** 页面，点击顶部 **「变配」** 按钮，即可随时在线弹性升降 CPU、内存或公网带宽。
